# Additional deliverable: LinkedIn Project showcase

As part of assignment_2, every student must create a LinkedIn post showcasing their project and learning experience.

The goal is not only to build the solution but also to communicate your work professionally, just as Machine Learning Engineers and Data Scientists do in industry.

## Your LinkedIn post should include:

### 1. Project Title

Example:

> Building an Object-Oriented news dataset builder with Python

---

### 2. Problem Statement

Briefly explain:

* What problem were you trying to solve?
* Why is collecting quality data important for Machine Learning?

---

### 3. What you learned

Mention concepts such as:

* Web Scraping with Requests and BeautifulSoup
* Data Collection for Machine Learning
* Pandas DataFrames
* CSV Export
* Python Classes
* Constructors (`__init__`)
* Methods and Objects
* Object-Oriented Programming (OOP)

---

### 4. What you built

Explain your solution:

Example:

> I designed a NewsDatasetBuilder application that scrapes news headlines from online sources, organizes the data into categories, creates a structured dataset, and exports it for future Machine Learning model training.

---

### 5. Key takeaways

Examples:

* Data collection is a critical stage of the ML lifecycle.
* Classes help organize and scale Python applications.
* OOP makes code more reusable and maintainable.
* Real-world ML projects require strong software engineering practices.

---

### 6. Include screenshots

Add screenshots showing:

* Your code
* Generated dataset
* Output/results
* Project structure

---
